# 🏎️ F1 Manager Dashboard

Painel de gerenciamento e dashboard de Fórmula 1 desenvolvido como parte dos meus estudos em Front-end e Back-end. O projeto permite a visualização dinâmica de pilotos e equipes através de uma integração entre um servidor Node.js e uma interface React.

## 🔗 Link de Acesso
- **Aplicação Online (Vercel):** [https://f1-manager-dashboard.vercel.app/](https://f1-manager-dashboard.vercel.app/)

## 🚀 Tecnologias Utilizadas

### Front-end
* React
* Vite
* JavaScript (Consumo de API REST via Fetch)
* CSS

### Back-end
* Node.js
* Fastify
* CORS (Configurado para integração com o frontend)

## ✨ Funcionalidades
* 📊 Visualização de pilotos e equipes da Fórmula 1.
* 🔄 Integração completa entre frontend e API dedicada hospedada em nuvem.
* ⚡ Dados carregados dinamicamente via requisições assíncronas.
